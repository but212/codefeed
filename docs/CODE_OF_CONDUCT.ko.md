협업, 기술적 토론 및 운영 원칙을 규정합니다.

## 적용 범위

저장소 내부 활동(Issues, PR, Discussions, 커밋 메시지, 코드 리뷰)에만 엄격히 적용됩니다. 외부 활동, 사적 영역, 개인 SNS 발언은 적용 대상에서 제외됩니다.

## 기본 원칙

- **사람이 아닌 작업을 비판**: 코드, 아키텍처, 설계에 대한 직설적이고 엄격한 비판을 권장합니다. 기술적 이견은 행동 강령 위반이 아닙니다.
- **전문가다운 협업**: 기술적 근거와 트레이드오프에 집중하며 상호 존중을 유지합니다.

## 금지 행위

- 인신공격, 모욕, 비방성 발언
- 괴롭힘, 스토킹, 원치 않는 지속적 접촉
- 차별 및 혐오 발언
- 동의 없는 사적 개인정보 공개
- 악의적인 기술 논의 방해
